# 地方政府單位預算「歲出計畫說明提要與各項費用明細表」解析工具

把**直轄市／縣市政府單位預算案** PDF 裡的「歲出計畫說明提要與各項費用明細表」轉成結構化表格。

> **⚠ 本工具僅供輔助核對，不能取代人工審閱——一切數據以政府公佈的預算書 PDF 原文為準。**

單一 HTML 檔、純前端（pdf.js 讀檔），**檔案不上傳**。

---

## 與中央版的差異

本工具與 [unit-budget-parser](https://github.com/cormort/unit-budget-parser)（中央機關「歲出計畫提要及分支計畫概況表」）是**不同的表**，故獨立成一個 repo：

| | 中央 | 地方 |
|---|---|---|
| 章節名 | 歲出計畫提要及分支計畫概況表 | 歲出計畫說明提要與各項費用明細表 |
| 工作計畫代碼 | 10 碼 | **11 碼** |
| 欄位 | 金額／承辦單位／說明 | **單位／數量／單價／預算數**／說明 |
| 金額單位 | 千元 | **元** |
| 說明 | 敘述段落，需靠規則鏈推論歸戶 | **逐明細列的短語，一對一** |
| 頁面兩側 | 無 | **直書標籤**（機關名／計畫名逐字直排） |

因為說明一對一綁在明細列上，中央版那整套歸戶規則鏈（名稱＋金額、加總、順序界限、孤兒句、橘底待確認）**在此完全用不到**。

## 層級

```
工作計畫（11 碼）→ 分支計畫（2 碼，後面不接空格）→ 用途別一級（4 碼結尾 000）
                → 用途別二級（4 碼）→ 明細列（單位／數量／單價／預算數／說明）
```

**分支計畫與用途別科目的判別**：分支是「2 碼後直接接名稱」（`05會計業務`），科目是「4 碼後有空格」（`2000 業務費`）。

另有兩種**不進驗算**的顯示層級：

- **計畫說明**：提要頁的預算金額與「較上年度預算數…增加…元。」，屬計畫層的增減說明。誤當明細會把它算進科目底下（實測臺中 6 筆不符全數由此而來）。
- **案別**：工程／資本門型計畫（臺北「一般建築及設備」）在分支之下還有「案」層——左欄空白、只有預算數，案號與名稱寫在說明欄（`03-113年個人電腦租賃費`），其下各有一組 3000/3030。案的金額是其下科目的小計（實測 448,000＝600＋112,120＋153,000＋91,560＋90,720＝分支總額），當成分支會重複計入、當成明細會算進上一個科目。因為同分支下同一個一級科目會出現多次，驗算對一級採**同 key 累加**後再比。

## 版面：一切座標都靠量測，不寫死

實測四個縣市，同一份 PDF 內就有多種版面，寫死座標必然失敗：

- **表頭橫跨兩列**：臺中「分支計畫及用途別科目」在 y=732，其餘欄名在 y=725，差 7pt。
- **欄名兩種寫法**：首頁「分支計畫及用途別科目」、續頁只寫「用途別科目」，置中後 x 差 22pt。
- **欄界取相鄰欄名的中點**：各欄的值相對欄名的偏移方向不同（單價欄名 315／值 320~344；預算數欄名 390／值 410~427；說明欄名 484／值 450），用欄名±固定偏移必然切錯。
- **說明欄左緣改用內文眾數**，且只算「不以數字開頭」的字——預算數與說明常併在同一個文字物件裡（`80,000 購置總預算編製作業手冊…`），一併計入會讓眾數落在金額欄上。
- **兩側直書標籤靠「同一 x 堆疊大量單字」偵測**，且只在表頭以下的資料區偵測：提要頁左側另有一組內層標籤（「歲出計畫說明」在 x=41），誤判會把 x=35 的科目代碼整批濾掉。

## PDFium 後備引擎

高雄市、新北市的內文字型 pdf.js 無法解讀（`g_font_error`），表格內一個數字都抽不到。
工具在 pdf.js 抽出 0 列時自動改用 `@embedpdf/pdfium`（MIT 封裝、底層 PDFium 為 BSD-3——
就是 Chrome 讓你能複製這些 PDF 文字的那顆引擎）：

- **動態載入**：只在 pdf.js 失敗時才從 CDN 下載（wasm gzip 約 2.0 MB），臺北臺中與一般檔案不受影響。
- **解析規則零改動**：PDFium 的字元流被組成 pdf.js 形狀的偽文件物件，餵給同一個 `parseLocalDoc`。
  兩引擎座標系一致（同一頁表頭 x 相同）。
- 字元合併間距 14pt 會把右對齊金額尾端與說明黏在同一個 run，但這與 pdf.js 在其他縣市本來就會
  產生的「預算數＋說明同物件」同型，交由既有拆分規則處理，行為一致。

## 使用

開啟 `index.html` → 選擇單位預算案 PDF → 解析 → 匯出 csv。

### 回歸測試

```bash
npm install && npm test
```

用 `examples/` 的真實 PDF 驗證，斷言機關名偵測與**四層加總驗算 0 不符**。測試直接呼叫 `index.html` 內的 `parseLocalDoc` 與 `reconcile`，不自行複寫規則。
